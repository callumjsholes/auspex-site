Privacy

Auspex Sports runs auspexsports.com. Contact: hello@auspexsports.com.

Email list

The site does not have accounts and does not ask anyone to log in. If you join the email list, the address is collected and stored by Beehiiv, the email service for this site. Beehiiv's privacy policy applies to that address. The public page is auspexsports.beehiiv.com.

What the address is used for

The list is used to send picks and to say if a paid tier opens. The list is not sold.

Visits

The site uses Cloudflare Web Analytics. It is cookieless and does not track individuals. It counts visits.

Hosting

The site is a set of static files on GitHub Pages. GitHub may keep ordinary server logs, such as the IP address of a request.

How to leave

Email hello@auspexsports.com to be removed from the list. Each message from Beehiiv also has an unsubscribe link.
